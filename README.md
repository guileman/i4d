# i4d

Sitio web de i4d. HTML + CSS + JS mínimo, sin dependencias ni fuentes externas.

- `index.html`: contenido (servicios, trabajos, clientes, contacto)
- `styles.css`, `script.js`: estilos y visor de imágenes
- `img/`: imágenes optimizadas en WebP

Para agregar un trabajo: copiar un bloque `<article class="work">` en la sección `#trabajos` y subir la imagen a `img/` (WebP, ~900 px de ancho).
